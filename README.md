## Bem-vindo! 👋

Obrigado por conferir este desafio de programação front-end.

Os desafios da Frontend Mentor ajudam você a melhorar suas habilidades de programação construindo projetos realistas.

**Para realizar este desafio, você precisa ter um bom entendimento de HTML, CSS e JavaScript.**

## O desafio

Seu desafio é construir este projeto de lista de produtos que inclui um carrinho funcional e deixá-lo o mais próximo possível do design fornecido.

Você pode usar quaisquer ferramentas que desejar para completar o desafio. Então, se houver algo que queira praticar, fique à vontade para experimentar.

Nós fornecemos os dados dos produtos em um arquivo local `data.json`. Assim, você pode usá-lo para popular a interface dinamicamente, se desejar.

Seus usuários devem conseguir:

- Adicionar itens ao carrinho e removê-los
- Aumentar/diminuir a quantidade de itens no carrinho
- Ver um modal de confirmação de pedido ao clicar em "Confirmar Pedido"
- Resetar suas seleções ao clicar em "Iniciar Novo Pedido"
- Visualizar o layout ideal da interface dependendo do tamanho da tela do dispositivo
- Ver estados de hover e foco em todos os elementos interativos da página
